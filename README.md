# Sinapse para Obsidian

Plugin (desktop) que configura e opera o [Sinapse](https://github.com/VoidPep/Sinapse-RAG): escolha quais pastas do vault entram na base de conhecimento, reindexe com um clique e conecte o Claude Code.
